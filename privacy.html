このアプリについて

「Youth成績」は、YouTube チャンネル「令和の虎Youthセレクト」の運営者本人だけが使う個人用の Google Apps Script です。

取得する情報

  • 運営者自身の YouTube チャンネルの統計（視聴回数、視聴時間、高評価数、登録者数の増減など）と動画のタイトル・公開日（YouTube Analytics API / YouTube Data API、読み取りのみ）

使い方

取得した情報は、運営者自身の Google スプレッドシートに書き込むためだけに使います。

第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。運営者以外のユーザーの情報は取得しません。

保存と削除

情報は運営者の Google スプレッドシートにのみ保存されます。アクセス許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

YouTube API サービスの利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。
